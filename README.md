# SJF-SRTF CPU Scheduling Simulator

## Project Overview
This project implements CPU scheduling algorithms using Java. It demonstrates how processes are selected for execution based on their burst time and remaining execution time.

## Objective
To understand CPU scheduling algorithms and simulate process execution in an operating system.

## Algorithms
- **SRJ (Shortest Remaining Job):** Selects the available process with the shortest remaining execution time. Confirm the exact definition used in this project with your teacher.
- **SRTF (Shortest Remaining Time First):** A preemptive scheduling algorithm that selects the process with the shortest remaining CPU time.

## Features
- Java-based scheduling simulation.
- Process scheduling and execution.
- Display of scheduling results supported by the implementation.

## Technologies Used
- Java
- Visual Studio Code
- Git and GitHub

## How to Run
1. Install the Java Development Kit (JDK).
2. Download this repository.
3. Open the project folder in VS Code.
4. Open the terminal in the project folder.
5. Compile the program:

   `javac SchedulingSimulator.java`

6. Run the program:

   `java SchedulingSimulator`

Run the program to see the actual scheduling results. The output depends on the input and features implemented in the code.
